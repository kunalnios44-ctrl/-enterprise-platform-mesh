# Enterprise Platform Mesh
**Internal Developer Platform (IDP) & Infrastructure Guardrail Reference Architecture**

A modular, policy-as-code platform engineering framework for multi-cloud resilience, zero-trust governance, and automated CI/CD pipelines across 9 core domains and 5 automated pipelines.

## Key Highlights & Quick Start
* **Architecture:** Modular setup (`.github/workflows`, `platform-guardrail`, `security`, `infra`, `platform`, `observability`, `dr-backup`, `tools`, `docs` with 19 ADRs) built with Python, Go, Terraform, Kubernetes, Helm, and Kyverno.
* **Verification:** Run `python3 tools/verify_guardrails.py --help` or `go test -v ./...` inside `platform-guardrail/`.
